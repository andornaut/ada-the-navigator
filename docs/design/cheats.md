# Cheats

Ada opens the browser-tab cheats through Settings. Any cheat starts a cheat session, saving play up to that moment first; from then on the scene's one save write is suspended and no achievement is earned, until play returns to the start screen, where the save from before the first cheat loads back. Show tips again, the FPS counter and Reset save are not cheats.

Reference: [cheats](../../gameplay/cheats.md).
