## Scope

Draw each weapon's HUD glyph and shop sheet from one pixel grid, specify projectiles, blasts, fans and beams, and name the starter weapon Laser.

## Criteria

- Laser, Multi-Laser, Rapid Missile, Heavy Missile, Scattershot and Phaser each have a 20 px HUD mask SVG and a two-frame shop sheet (`icon-shop-weapon-laser` for Laser).
- Weapon pickups draw the weapon's glyph at 14 px in amber inside the pickup square.
- `art/weapons.md` specifies missiles, blasts, the Multi-Laser fan and the Phaser beam to each level's range, with reduced motion holding missile frame 0.
- The retired Triple Laser, Missiles, pierce, spread and 24 px glyphs are removed from assets and docs.

## Decisions

- The user chose Basic icon B and Phaser icon A, and pickups showing the HUD glyph in the amber square.
- Basic is renamed Laser everywhere, with renamed icons.
