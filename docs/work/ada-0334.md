## Scope

Use the published action binding for Map field selections through the existing
action root. Keep the selected physical target from the gesture start, and use
the existing callback for both short release and the default 500 ms hold.
Remove the separate activation from the Map's pointer-release handler.

Complete verification of discrete action ownership across the current game.
Keep explicit hold overrides, keyboard semantics, foreground and readiness
guards, cancellation, drag, pan, pinch, wheel, editable controls and focus.

## Criteria

- Actual Map tap and hold on the same item or blank field each route one action.
  Move, pinch, cancellation, modal coverage and disposal prevent stale actions.
  The held gesture's native release click cannot select a second item.
- Preserve current target geometry, selection order, map and focus behavior.
  Cover the actual native Map in normal gameplay, including touch and keyboard.
- The construction and architecture checks cover completed discrete controls
  and fail for unbound action paths or an extra activation owner. Classify
  continuous input, focus, visual effects and suppression using actual
  callback behavior. Preserve the explicit gesture and device shortcuts.
- The full gate passes and the exact reviewed source follows normal delivery.
