## Scope

Overlap installed-game version discovery with startup and keep the existing
progress indicator meaningful while an update prepares, downloads and applies.
Consume the shared change through the published Game Kit package.

## Criteria

- Start one real version check earlier without delaying Start on slow or
  unreachable servers. Keep normal retry and verified staging.
- Show preparation once a successor is confirmed, real byte progress during
  download, and activation through the reload into the new build.
- Preserve explicit acceptance, save and version checks, one navigation, and
  offline play. Measure the new timing in an older installed browser profile.
