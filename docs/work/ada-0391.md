## Scope

The shared procedural systems policy allows no routine seed sweeps. The test
recipe reruns seed-dependent suites in one alternate world after the default
run. Remove that routine rerun and keep replay of a specific world on demand.

## Criteria

- `npm test` and the gate run the default suite once; no alternate-world pass.
- `ADA_LAUNCH_SEED=<n> npm test` still replays a specific world.
- Seed-dependent behaviour stays pinned by contract and property tests and the
  fixed acceptance batch.
- docs/checks.md describes the single run.

## Decisions

- Linked to game-coordinator gc-0028.

## Outcome

The default test gate runs one pinned launch-seed suite. The change shipped
in `2d131d61`. An explicit seed-7 run through `npm test` verified on-demand
replay for Needle flight and state protection. The hand-placed frigate
fixture uses a fixed approach lane so unrelated moving debris cannot prevent
the initial hit.
