## Scope

Improve Earth Storybook backgrounds with slightly more vibrant color and
plausible furniture and prop placement. Reuse backgrounds where the same base
fits distinct scenes or states.

## Criteria

- Compare the rendered scenes in supported landscape and tall crops. Keep key
  story details above the lower dialogue panel.
- Preserve distinct scene and state identities, original source art, current
  copy, character placement semantics and navigation.
- Verify fewer emitted background files where bases are reused. Check the
  existing Storybook loader, cache and offline coverage before retiring files.
