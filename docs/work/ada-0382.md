## Scope

Under the shared saves-and-cheats policy (game-coordinator gc-0025), cheats act
on the real save like normal play. Remove Ada's cheat session.

## Criteria

- Cheats, and play after a cheat, save, earn and bank as usual: story progress,
  unlocks, ownership, levels, Stardust, ore, jobs, achievements and statistics.
- Returning to the start screen or reopening the game keeps cheated progress;
  Continue loads the real save.
- Cheats on the start screen apply to the next Start or Continue.
- Restart on the start screen still returns to a new save.
- Remove `src/game/cheatSession.ts` and the session state and hooks in the scene,
  scene UI and game model, with their tests updated.
- Gameplay replaces the Cheat session rules in the cheats design document.
