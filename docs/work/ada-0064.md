## Scope

Draw the start screen after Chibi's with the ship, wordmark and actions, open every launch on it
after the update check, resume a saved flight on Continue, and add Exit where the platform can act.

## Criteria

- Restart precedes Continue in Tab order.
- Focus returns to the default button when the update offer closes.
- Restart clears a held mid-flight save.

## Decisions

- Exit uses Art's exit glyph at the far top right.
