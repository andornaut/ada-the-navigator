## Scope

Replace one SVG file per frame with one SVG sheet per asset set plus frame data, for every set in `public/art/` including Ada's ship and the non-portrait UI icons. Sheets stay vector. Tech owns the loader and manifest side and sets the maximum sheet size from mid-range Android texture limits; a set that does not fit is split.

## Criteria

- Art file count drops from 8,323 to about 150 on the measured build, with every frame still addressable by its current key.
- Each sheet stays within Tech's verified maximum sheet size.
- Rendered frames are pixel-identical to the current per-frame SVGs at 1280x720 and 720x360.
- Before and after file counts and compressed bytes are reported.

## Outcome

The earlier production baseline at `fdd76220` used 25 precache packs. In
paired fresh Chromium runs, same-origin network responses fell from 6,805 to
43 and encoded response bodies fell from 7,600,704 to 5,207,178 bytes.
Both builds durably cached all 6,811 manifest URLs. Pack downloads reduce
network requests while keeping each existing asset URL addressable.

A first cold install on production `e0ef388e` reached Start in 3.736 s. By
then, 60 same-origin responses across 58 distinct paths transferred 6,193,276
encoded body bytes. The 47 durably cached gzip groups accounted for 6,066,819
of those bytes. The release had 120 published output files, 474 physical Art
files checked in under `public/art/`, and 485 logical URLs in the build
manifest.

Build `5b8b89b0ed725ffb` has 120 deployed files and 484 logical
manifest entries. Its 47 gzip groups total 6,129,608 encoded body bytes.
The selected art inventory has 476 physical Art files and no loose
animated SVG frames in active manifests. The four Aboard fallback
source frames remain available in the repository. The installed
desktop app read the new Play and geometry archives offline on this build.

Seven SVG documents exceed the conservative 2048 source envelope.
The loader's member size calculation is an estimate. The physical Android
texture limit and complete two-size pixel parity remain open.
