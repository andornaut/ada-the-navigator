## Scope

Use the shared rectangular button's intrinsic width in the Galaxy Map footer.

## Criteria

- Jump to Sunflower fits on one line with standard text size and padding.
- The single button stays centered and clears the panel above it.
- Preserve locked destination labels and press behavior.

## Decisions

## Outcome

Deployed in `0d96a53c`. Browser verification showed one centered line with
the standard text size at the wide and phone viewports. A fresh Start
playthrough reached the actual inset Galaxy Map and measured an 8 px
gap from the preview at 720 × 360. Locked destinations still use their
existing labels and actions.
