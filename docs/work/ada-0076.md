## Scope

Adopt game-kit's start from disk, require a newer save's version with an update-required notice, and
restore only complete saves of the current version with no migration or defaults for older shapes.

## Criteria

- A newer save reports its update state once.
- An older or incomplete save does not restore.

## Decisions

- Saves reset rather than migrate before version one.
