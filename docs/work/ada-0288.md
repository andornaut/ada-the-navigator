## Scope

Pin game-kit 0.58.1, whose verified JSON check ignores response headers without body
semantics, so the Cloudflare HTTP/3 `priority` and `server-timing` headers no longer fail the
first install on Android Chrome.

## Criteria

- The pin is the published 0.58.1 tarball with lockfile integrity matching its release.
- The full gate passes on the exact revision.
- A fresh install with the Cloudflare headers injected reaches Start in emulated Android Chrome.

## Decisions

- The pin moves from 0.56.1; 0.57.0 removes update calls Ada does not use and 0.58.0 adds
  `canExitApp`.
- The update switch timeout and the single install event are fixed separately in the loader
  rework.

## Outcome

`package.json` and `package-lock.json` pin game-kit 0.58.1.
