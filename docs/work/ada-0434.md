## Scope

Use current engine top speed for both ring color and crossing eligibility.
Start course guidance automatically on approach to the green flag.

## Criteria

- Turn the next ring green below 50 percent, yellow from 50 up to 75 percent
  and red at 75 percent or faster. Only the green speed band allows crossing.
- Update color immediately when the speed band changes. Exercise the actual
  flight view with the shipped ring assets and different engine levels.
- On approach to the current course flag, give the short Loom instruction
  and mark the next uncleared ring. The flag has no Use action.
- Preserve cleared rings when Ada returns to the flag. After a fast miss,
  guide her back to the same uncleared ring.
