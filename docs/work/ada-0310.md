## Scope

Keep the 2:1 game area with bands, and centre it in every frame, turned and unturned, so the
spare space splits into equal bands on both sides of each axis. Every part that reads the game
area follows it: the cameras, the `--ada-area-*` and `--ada-hud-*` properties, the HUD rect, the
sticks' clamp, modals, the start screen, the galaxy map chart, edge markers and scan receipts.
The shield pill's drawn bottom sits 12 logical px above the game area's bottom, as the pause
disc's drawn top sits 12 below its top. Edge markers snap to device pixels in the frame's axes.

## Criteria

- `playView` and the camera's `playViewport` share one origin, `floor((view - area) / 2)` on
  each axis in logical px, the camera's on the nearest device pixel.
- The shield pill's drawn bottom is on the HUD rect's bottom edge, `HUD_EDGE` (12) above the game
  area's bottom.
- An edge marker's outermost drawn pixel sits `EDGE_MARKERS.gap` (1) inside the safe game area,
  moved inward by less than one device pixel, in a turned frame too.
- Focused tests for each change; browser smoke in the turned 744x396 CSS frame (1.88:1) measures
  equal bands, equal pause and shield gaps, and the marker gap on rendered pixels.

## Decisions

- Supersedes the shield placement of ada-0010 and ada-0182, whose drawn bottom sat 14.5 above
  the viewport bottom and so moved into the band on a frame narrower than 2:1.
- Bottom edge markers treat the shield pill like every other control: they stay on the edge
  and draw under it (user, 2026-11-18).
- The sticks keep their documented exception: 50 from the screen's sides and bottom, clamped 8
  inside the game area.
- Covers ada-0001's first criterion, the game area centred in the turned frame. Its other two
  criteria, the canvas filling the display and controls mapped to the visible frame, need their
  own proof on iPhone.

## Outcome

Shipped in the commit that adds this file. In the turned 744x396 CSS frame at devicePixelRatio
30/11 (Chromium), the bands measure 31 and 34 device px (11 and 12.1 logical) where one 65 px
band sat below the game area. The pause disc's drawn top and the shield pill's drawn bottom sit
34 device px (12 logical) from the game area's drawn edges, and a bottom edge marker's drawn
edge 4 device px (1.4 logical) inside it, against 5.9 before. Headless Firefox in the check container
has no WebGL, so the WebGL-only game does not start there; Firefox is unmeasured.
