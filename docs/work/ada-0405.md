## Scope

Reduce duplicate tests and repeated setup using the current isolated suite as a
baseline. Use data-driven cases for equivalent behavior with distinct inputs.

## Criteria

- Record the comparable test count and elapsed time before and after changes.
- Verify each deletion against a surviving regression check. Account for the
  mutation or other causal evidence that distinguishes real edge cases.
- Preserve production behavior, distinct input boundaries and required checks.
- Run the exact combined gate before the normal release.
