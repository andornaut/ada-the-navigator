## Scope

Adopt published Game Kit 0.59.4 for the installed game's reconnect and resume
update discovery. Preserve explicit Update now, offline play and saved progress.

## Criteria

- Check a previously installed build can update to the new release. Verify the
  new release discovers a subsequent build while already open on reconnect.
- Keep the active build usable through staging and verify the updated game can
  launch and continue the same save offline.
- Qualify the exact release through the combined checks and normal delivery.
  Record the limits of browser-based resume verification.
