## Scope

Apply the shared one-layer navigation rule to Ada. Keep actual pause state,
focus restoration and input isolation.

## Criteria

- Back returns to the immediate invoking view, including title Menu,
  in-game Pause, nonpausable Menu and nested pages.
- Close dismisses one dialog to its underlying view. A directly opened HUD
  dialog returns to gameplay. Resume explicitly returns to active play.
- X, Escape and backdrop use the same one-layer destination where dismissal
  is allowed. Preserve mandatory choices, Cancel and confirmation guards.
- Keep the Menu button below every modal and unavailable while covered.
- Verify labels, actual destinations, paused state and restored focus for
  the affected routes. The checked source follows normal delivery.
