## Scope

Use Game Kit to render standard text and icon buttons across menus, modals, the
HUD and standalone controls. Reuse loading-safe Retry. Ada supplies the skin,
labels, placement and callbacks.

## Criteria

- Inventory every standard button and extend the existing construction check
  to prevent new bypasses. Preserve continuous steering, dragging, sliders and
  native editing.
- Preserve control states, discrete input and hold behavior. Retain game-styled
  keyboard focus, forced-colors visibility, navigation and modal focus restoration.
- Use the verified public Game Kit package. Document the exact pin and inventory
  coverage. Check keyboard, pointer and touch interactions, including hold and
  modal restoration, in the actual game. The checked source follows normal delivery.

## Decisions

## Outcome

Build `19e7b707` uses public Game Kit 0.95.1 for standard text and icon
buttons, including the loading-safe Retry. Ada owns the skin, placement,
labels and callbacks. The production census reviewed 553 files and found
no raw standard button or native discrete listener. The construction
check rejects a raw Close with the standard styling even when its
activation is registered. Steering, dragging, sliders, native editing
and spatial map and Use controls keep their specialized input paths.

Chromium checks covered pointer, touch hold and release, keyboard
activation, focus restoration across nested modals, and forced-colors
visibility. The broader discrete-input audit remains under Ada-0334.
