## Scope

Use Game Kit to render standard text and icon buttons across menus, modals, the
HUD and standalone controls. Reuse loading-safe Retry. Ada supplies the skin,
labels, placement and callbacks.

## Criteria

- Inventory every standard button and extend the existing construction check
  to prevent new bypasses. Preserve continuous steering, dragging, sliders and
  native editing.
- Preserve control states, discrete input and hold behavior. Retain game-styled
  keyboard focus, forced-colors visibility, navigation and modal focus restoration.
- Use the verified public Game Kit package. Document the exact pin and inventory
  coverage. Check keyboard, pointer and touch interactions, including hold and
  modal restoration, in the actual game. The checked source follows normal delivery.
