## Scope

Give the installed-app Exit icon the existing Pause and Menu outline, ring,
face and glyph colours while retaining its door-and-arrow symbol. Preserve
the top-right anchor, native action, hit target, focus and visibility rules.

## Criteria

- Idle and pressed Exit match the navigation family at the same optical size
  in base and phone-inset views of Start and flight.
- Exit remains available only in the existing closable installed-app context.
  Mouse, touch, hold and keyboard actions retain their current behavior.
- Art reviews the rendered icon. The checked source follows normal delivery.

## Decisions

## Outcome

Exit remains a standalone top-right control in a closable installed app. Its
door-and-arrow artwork uses the same rim, ring, face and glyph treatment as
Pause and Menu. Art accepted the idle and held appearance in the base and
phone-inset Chromium captures. The existing action and focus contract remains
in place. The checked source reached production in `81856c3d` on 2026-11-22.
