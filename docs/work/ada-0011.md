## Scope

Align the Ship card spec and the ship keyline rules in `art/layout.md` and `art/galaxies.md` with the rendered game.

## Criteria

- The Ship card is the shared Large card with the close X, three top-aligned equal columns (Cargo, Equipment, Weapons) separated by page dividers, and one centred primary Back. Back, the close X, Escape and back return to Paused.
- The keyline table covers every keylined object, shot, beam, indicator, marker, jet, effect and the status pill, matching what the game draws.
- No rule describes geometry the game does not render.

## Decisions

- The docs follow the rendered game, and source constants are named where they exist (`SHIP_CARD`, `shipTree`).

## Outcome

Specified on `art-doc-ship-keyline` (cb13928a); on `main` as `51e0f33a`. The Large width there is superseded by [ada-0012](ada-0012.md).
