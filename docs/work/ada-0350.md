## Scope

Apply the shared Controls and input policy to Ada's game buttons. Cover
HTML and canvas controls, including Start, menus, modals, the HUD,
loading Retry and crash recovery. Use the shared Game Kit rendering
and input lifecycle for standard buttons.

## Criteria

- Show focus, pressed and selected states with a visible change in face
  fill, text or icon color. Keep the ordinary borders that appear in all
  states. Do not use added outlines, border rings or ring-shaped shadows.
- Keep disabled states distinct. Preserve keyboard focus, tab order,
  activation and focus restoration, including in forced-colors mode.
- Audit the current source and verify the rendered states. Check the
  shared defaults and game-specific styles with keyboard and pointer
  input. Record the checked revision and normal deployment evidence.
