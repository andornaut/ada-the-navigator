## Scope

Follow the shared homepage layout and show concise Flight and Menus tables
using Ada's actual keyboard, mouse and touch inputs.

## Criteria

- Keep the themed hero, a compact About section, Controls and footer in
  that order within one responsive content column.
- Use semantic tables with Action and Input headers and readable key names.
- Keep the page readable on narrow screens and preserve Play, Install, and
  all existing in-game controls.
- Verify the source and served page through normal delivery.
