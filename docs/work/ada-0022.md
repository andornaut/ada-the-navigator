## Scope

Start each local check only when resources are available, record container start ownership, and run
the check categories through a Make container profile that CI and the scheduled gate share.

## Criteria

- A check starts only below the load threshold.
- Make enters the canonical container launcher directly.
- CI and the scheduled gate run the same Make checks and propagate failures.

## Decisions

- Resource availability is the only container start policy; there are no blackout periods.
- The workspace uses canonical ownership without Git trust overrides.
