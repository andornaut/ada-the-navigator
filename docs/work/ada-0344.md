## Scope

Apply the shared 4 GiB ceiling to new Ada browser verification and preview
containers. Keep the local gates at their existing 4 GiB and the scheduled gate
at its existing 4096 MiB.

## Criteria

- Check the actual Docker memory limit. Preserve existing CPU and worker caps,
  filesystem isolation, resource admission, source checks and artifact capture.
- Collect a representative native browser run with peak memory and available
  OOM evidence. Keep an active container's cap until its run finishes.
- Keep existing runner controls, schedules and ownership. The checked source
  follows normal delivery.
