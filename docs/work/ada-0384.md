## Scope

Redesign all stations from scratch, without reference to the current station art. References: the stations and capital structures of popular science fiction film and television (Star Trek, Star Wars, Battlestar Galactica, Babylon 5 and films that feature space stations), and Ada's ship: clean lines, simple shapes and few details. Stations read as very large structures seen from farther away than Ada's ship, so they use large shapes only, with no small bays or turrets. Each station uses a few mostly flat colours. Each galaxy has a theme that its station's form follows, such as a spiral for Whirlpool and a central hub with radiating petals for Sunflower. Sizes follow the current stations and may vary. Mock-ups in several styles come first; the user directs the changes, and variations follow once a reference is settled.

## Criteria

- Several mock-up styles are shown at game scale on each galaxy's field for the user's direction.
- Production starts only after the user settles a reference.
