## Scope

Use the Shop refusal cue for attempted activation of visible disabled and
unavailable buttons across Ada, beginning with both Exchange quantity rows.
Keep the existing action root and use the shared red label and shake cue.
With Reduced motion enabled, tint the label red without shaking it.

## Criteria

- A refused action keeps its disabled face and readable label at rest. It
  never executes the action or mutates the game.
- Use the same cue for supported pointer, hold and keyboard attempts. Respect
  modal coverage, readiness, focus and disposal.
- In Exchange, announce the affordability reason without a visible inline
  refusal line. Preserve other transaction errors and their existing display.
- Verify both Exchange directions and representative remaining controls through
  actual game views, including Reduced motion and guarded input.
