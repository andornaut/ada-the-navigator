Give cards bottom-right Close and Back footers, centre a row with one visible button, and label
modal returns Back or Close from the caller's context.

## Criteria

- A sole visible button is centred.
- Back versus Close follows the actual return context.
- Dismissal closes only the top modal.

## Decisions

- Requests `button-center` and `footer-labels`.
