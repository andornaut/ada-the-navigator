## Scope

Remove the 217 duplicate copies in `public/art/` (3.2 MB raw), mostly `enemies/*-hardpoints.json` repeated in each galaxy folder, by storing each shared asset once and referencing it from the galaxy manifests.

## Criteria

- No two files under `public/art/` have identical content.
- Every galaxy still resolves each enemy asset, and enemy rendering is unchanged.

## Decisions

## Outcome

Each shared enemy and ship file is stored once and the galaxy manifests and sidecars maps point
at it: 216 duplicate copies removed (3.18 MB raw), with every manifest key resolving to the same
bytes. The cargo hauler reads the retaliator's hardpoints and jets, the industrial hardpoints
are core precache files, and the verified JSON body families are removed since no duplicates
remain.
