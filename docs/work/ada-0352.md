## Scope

Use the shared button sizing policy for labeled rectangular actions, including the
Start screen, menus, modal footers and story navigation. Round icon controls keep
their own sizing.

## Criteria

- Use the same larger label size, standard single-line height and text padding.
- Give a vertical stack a shared width. In a horizontal row, give each button the
  width of its own content plus standard padding, including in wrapped rows.
- Keep a sole visible action centered. Preserve action order, keyboard focus,
  pressed feedback and click and hold behavior.
- Verify rendered widths and fit in landscape and turned portrait, including groups
  that switch orientation at narrow widths.
