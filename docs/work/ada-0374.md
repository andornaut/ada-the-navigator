## Scope

Store the FPS counter choice through the same device preferences as Move controls,
Aim controls, Sound effects and Reduced motion.

## Criteria

- Restore either FPS counter choice when a new game document loads, with Off as
  the default for a device without a stored choice.
- Keep all five choices across reload, reopening and a same-origin game update.
- Store preferences independently of saved progress and retain each setting's
  current effect and default.

## Decisions

- The FPS counter choice persists beyond the page session.

## Outcome

Ada stores FPS with the other device preferences independently of progress.
The implementation deployed in `2c4d5304`. Native Chromium verified both FPS
choices across reload and reopening. An explicit update from that build
restored all five choices in one new document with a byte-identical save.
