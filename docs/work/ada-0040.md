## Scope

Add the layout module that implements `art/layout.md`, size the DOM UI in logical pixels, fail on
raw pixel literals, and build the start screen, station card and shop on the shared card builder.

## Criteria

- No raw pixel literal remains outside the base button.
- Only a card's scroll group scrolls.
- Every computed layout result is recorded in a canonical dump.

## Decisions

- Layout tokens are the single source for UI sizes.
