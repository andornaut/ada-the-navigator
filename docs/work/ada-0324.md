## Scope

Pin the released game-kit 0.59.1 and move Ada to its page-driven installer and router service
worker. The launch runs from the boot shell before the game module downloads, installs the
complete build under the one loading bar, and plays from the cache. Galaxy precache groups and
their background downloads are removed. The build pointer `/.game-kit/build.json` is served
`no-store` and each build manifest as immutable. The landing page registers the router. A staged
update is offered in session through the existing Update available card, which pauses play on
any screen; a dismissed update activates silently at the next launch. A first install the browser
refuses, or that storage cannot hold, plays from the network with Gameplay's notice.

## Criteria

- The released archive is pinned by URL and SRI, with no vendored copy.
- A fresh install, a killed install that resumes, offline play, an update that fetches only
  changed files, a redeploy during install, the in-session prompt, the next launch's silent
  activation and both network-play cases pass the headless browser harness with Cloudflare's
  HTTP/3 headers, at 1.6 Mbit/s with 300 ms and at 3G (400 kbit/s, 2,000 ms).
- The install lists the same files and size as 0.58.2's precache.

## Decisions

- The complete build installs before first play (policy 93aa783), replacing the progressive galaxy
  precache of ada-0118; its JSON compaction stands.
- `soundFormat` is undefined: Ada makes its sounds at runtime and ships no sound files.
- The boot fonts and UI art load after the launch resolves, from the installed build, so they do
  not compete with the install's download.
- The network-play notice uses the save status slot, shows once per launch from the first flight
  and times only while it shows.

## Outcome

Adopted 0.59.1 (source 8112dae8), the 0.59.0 loader (source 233e882c) with a required-loading
Retry fix. Harness on the 0.59.0 release candidate: fresh install 485.7 s at
1.6 Mbit/s and 3,021 s at 3G; killed install resumes with no stored file fetched again; an
update fetches 5 changed files and switches in 3.4 s; a redeploy during install reloads once into
the new build; the prompt pauses flight and the next launch activates the staged build with no
download; network play shows its notice for about 8 s. The install lists 8,340 files and
38,347,917 bytes against 0.58.2's 8,340 and 38,338,453 on the same source. On the release pin,
after the enemy asset dedupe, the build is 7,317 files and 31,865,874 bytes and installs in
439.4 s at 1.6 Mbit/s.
