## Scope

Apply the shared keyboard focus policy (gc-0017) to Ada's controls, including
station purchase confirmation and other modal actions. Use the existing
shared control primitives where they cover the affected controls.

## Criteria

- Use a visible game-styled keyboard focus state, including in forced-colors
  modes. Preserve native focus, tab order, activation and restoration.
- Preserve ordinary graphic borders and distinguish focus from pressed,
  selected and disabled states.
- Check actual pointer use, Tab and keyboard activation, modal dismissal and
  restoration. Record the affected caller styles and checked delivery.

## Decisions

## Outcome

The dialog, galaxy map, Ship, and station purchase controls use the shared
game focus treatment. The checked revision `2889c45c` reached production
on 2026-11-22. Chromium verified visible focus on dialogue Skip, Galaxy
Jump, Ship, and the purchase confirmation, including forced-colors
Highlight. Keyboard Cancel restored focus to the original offer and left
the balance unchanged. Phone inset emulation was checked. Physical display
cutouts remain unverified.
