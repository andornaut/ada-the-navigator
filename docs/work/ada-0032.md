## Scope

Select Ada's authored ship view from heading metadata, render speed-scaled jets from Art's jet data,
and fire from Art's nose point for each heading.

## Criteria

- The sprite snaps to the nearest authored heading.
- Shots leave from the nose point of the drawn heading.
- Thrust frames load only when speed jets are missing.

## Decisions

- Jets scale by Ada's tuned top speed.
