## Scope

Measure the drawn-pixel padding of every pill and button not yet audited, against the rule that padding and margins are equal as drawn, counting icon side bearings. Deliver a mock-up sheet of mismatches with proposed fixes for user review before any production change.

## Criteria

- Each pill and button is measured on rendered pixels at 1280x720 and 720x360 with phone insets.
- Each mismatch lists the element, the measured sides, the rule value and the proposed fix.
- No source or asset changes before the user approves the fixes.

## Decisions

## Outcome

The retained matrix in `ada-0278-completed-visible-pixel-audit-7ee9bc1e`
records drawn-pixel measurements for 63 desktop cells at 1280x720 and 62
phone cells at 720x360 with insets. Three cells are inapplicable at each
viewport. The one historical phone Next cell is capture-only. Continue
replaced Next and has a separate measurement. No current fixture cells are
missing. Each measurement applies to its named source build and state.

The parent reviewed the exact retained captures for the final eight inset
cells at `7ee9bc1eb1d2aa38bd2001699a49a9c4f1dcb21d`. The Ada name tab
and Multi-Laser disc still have 2 px opposing-side differences, vertical
and horizontal respectively. Both remain minor, with no additional fixes
approved.

The original 66 classifications remain 32 pass, 23 minor and 11 mismatch.
The eleven original mismatch proposals and the user's approval are
preserved under [Ada-0291](ada-0291.md).
