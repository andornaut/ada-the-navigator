## Scope

Use the approved same-weapon, same-level firing rates by mount and route
pair. Match fixed front Lasers to frigate turret Lasers. Use the approved
fixed intervals for Charged Lance, Mine Layer and Ring Burst.

## Criteria

- Apply 25%, 35% and 45% to baseline shared mounts, and 40%, 50% and 60% to
  the higher band. Preserve damage, warning behaviour and platform bursts.
- Initialize hostile station mounts in stable armed order using each mount's
  own interval. Preserve live and saved clocks and keep surviving mount indices.

## Outcome

The cadence and stable clock initialization landed in `d575e1aa4`, with
approved Gameplay rules paired in `2a7e3bb09`. The isolated 533-case cadence
regression run covered shared rates, station mounts, and saved clocks. The
implementation is included in public build `ec2ce101c`.
