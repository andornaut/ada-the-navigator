## Scope

Share full dialog chrome and footer policy, fit Settings and Ship to the available space, page
station catalogs and quest details, fit modal content within shared width presets inside the safe
game area, and adopt the two-column Settings layout.

## Criteria

- Content is measured before the width clamp.
- Settings fits without scrolling.
- Modals use fixed presets within the safe game area.

## Decisions

- The retired full-modal option was removed.
- Settings shows current states with accurate descriptions.
