## Scope

Remove one-off UI markup and styles so every screen renders from design tokens
and shared components, and align components through a small set of layout
primitives.

## Criteria

- Phase 1: the raw-pixel guard covers style modules in `src/ui/layout/` and
  `src/style.css`, and its allowlist names only existing files.
- Phase 2: the global `button` rule in `src/style.css` and the
  `.ada-controls button` rule are removed, and the legacy `.story-panel` path is
  removed once it is shown never to render.
- Phase 3: UI colours come from one colour token module; no literal hex colours
  remain in UI styles.
- Later phases: a round HUD disc component, a row-or-stack action group, one text
  button path (ada-0342), and migration of screen-private layout schemas to the
  shared schema, built on Game Kit components and structural nodes.

## Decisions

- Side-by-side buttons are 16 px apart everywhere, footers included; stacked
  standard buttons stay 8 px apart.
- Footers keep pinned edges: secondary button at the left, primary at the right.
- The row-or-stack action group, round icon button, modal frame and colour
  token mechanism belong in Game Kit, and Kit structural row, stack and columns
  nodes become the base layout primitive.
- Start phases 1 to 3 now.

## Outcome

The raw-pixel guard covers the layout style modules and the page stylesheet.
The blanket button styles and unused story-panel route were removed. Runtime
styles read the named colour tokens, including build-time expansion in the
boot and crash stylesheets. The guard checks authored layout and modal style
sources. The separate modal style module preserves all seven existing style
exports byte for byte.

The Cheats resource grants use the shared equal-column node. The paired
browser comparison matched rendering and button placement at 720×360
and 1280×720.

Settings uses the shared stack for each group of switches. Paired browser
captures matched the card layout and retained the focused switch during
the column change.

The standard button migration is complete under Ada-0342. The remaining
common action group and screen layout migrations stay open.
