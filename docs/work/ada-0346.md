## Scope

Remove the Exit entry from the Start Menu. The standalone Start screen Exit
disc and its shortcut continue to follow the installed-app capability rule.

## Criteria

- Start Menu shows Achievements and Settings, then Close. Preserve navigation,
  background dimming, and focus return.
- Check the menu and standalone Exit in a browser tab and a closable installed
  app fixture. The checked source follows normal delivery.

## Decisions

## Outcome

The Start Menu shows Achievements and Settings above Close. Exit remains
a standalone control when the installed app can close. Chromium checks of
a browser tab and a closable installed-app fixture verified the menu rows,
dimming and focus return. The checked source reached production in
`81856c3d` on 2026-11-22.
