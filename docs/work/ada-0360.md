## Scope

Make each dismissible modal's top-right X invoke the same Back, Close,
Cancel or Resume action as its other dismissal controls.

## Criteria

- Include the header X in the top modal's live scope. Dispatch once through
  mouse, tap or hold, and restore the immediate parent and invoking focus.
- Preserve the existing confirmation and mandatory-choice guards.
- Verify the reproduced Pause failure and its fix in a real game build.
  Audit other modal callers and record the actual native coverage.

## Decisions

## Outcome

The Pause header X now resumes through the same action as the footer.
Native browser checks reproduced the old mouse and touch failure and
verified both inputs on the fixed Pause. Representative checks cover Map,
Ship, Settings, Achievements, Quests, Cheats, Station and Install Steps.
Letterbox dismissal targets the top modal. The mandatory Story choice stays
open.

The held Update X deferred a real staged offer once, without navigating.
Focus returned to the same Start control and stayed there after touch
release. The staged build and save were retained.
