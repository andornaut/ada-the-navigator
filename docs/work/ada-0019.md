## Scope

Build a playable prototype with placeholder graphics to test the core concepts: the content and
tuning contract, a serializable model, deterministic flight and combat, quest progression, snapshot
persistence, the renderer with an accessible story shell, independent flight controls and a browser
smoke.

## Criteria

- The prototype chapters are playable end to end in the browser.
- Flight state persists across reloads.
- The browser smoke covers dual touch, resolution and persisted coordinates.
