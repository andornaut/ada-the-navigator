## Criteria

- Paint, weapon, resource, equipment and cargo details opened from Ship use
  Back and return to Ship with focus on the invoking row.
- The same details opened directly from the HUD use Close and return to play.
- Apply the same return-context rule to other dialogs. Match the header X
  destination to the footer dismissal wherever both are available.
