## Scope

Bring Ada's procedural systems in line with the shared policy beyond the
ada-0380 planner: one predicate per admit or refuse decision, resumable draw
counts, and pure entry points for encounter and enemy logic.

## Criteria

- Each admit or refuse decision (spawn admission, first-sight engagement
  admission, attack gates) is one predicate that returns its refusal reason.
- A resumable run saves the draw counts of every stream it continues.
- Encounter and enemy logic entry points take explicit context, state and input,
  context first and subject last, and read no engine object or module state they
  are not handed.
- Gaps found by the audit are listed here before changes start.
