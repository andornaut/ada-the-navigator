## Scope

Show one dialogue-style badge above the boss bar, using the captain name
when available and the ship name otherwise. On Hammer's bar it reads
Captain Tally.

## Criteria

- Keep the name attached to the top-left of the meter, with nothing below it.
- Preserve hull values, disabled state for assistive technology and normal
  salvage controls.

## Outcome

The single name badge landed in `fc2a08fa7`, with matching early encounter
captions in `cdb4a470d`, and shipped in `ec2ce101c`. Exact Chromium captures
showed Captain Tally alone above Hammer's meter. The disabled meter exposed
the correct hull value and accessible disabled text alongside Salvage.
