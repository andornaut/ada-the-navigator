## Scope

Show one dialogue-style badge above the boss bar, using the captain name
when available and the ship name otherwise. On Hammer's bar it reads
Captain Tally.

## Criteria

- Keep the name attached to the top-left of the meter, with nothing below it.
- Preserve hull values, disabled state for assistive technology and normal
  salvage controls.
