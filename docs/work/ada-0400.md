## Scope

Use the medium modal width for the crash screen, with a normal Copy button
on the left and primary Reload on the right when both actions are visible.

## Criteria

- The panel uses the shared medium width with the existing viewport and
  safe-area limits. Both single-line buttons use the shared action height.
- Copy stays associated with the developer's error details. When Reload is
  the sole visible action, center it.
- Preserve native copy, reload, focus, pressed and hold behavior and the
  existing save fence. Verify at base and wide viewport sizes.
