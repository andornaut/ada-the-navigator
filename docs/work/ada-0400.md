## Scope

Use the medium modal width for the crash screen, with a normal Copy button
on the left and primary Reload on the right when both actions are visible.

## Criteria

- The panel uses the shared medium width with the existing viewport and
  safe-area limits. Both single-line buttons use the shared action height.
- Copy stays associated with the developer's error details. When Reload is
  the sole visible action, center it.
- Preserve native copy, reload, focus, pressed and hold behavior and the
  existing save fence. Verify at base and wide viewport sizes.

## Decisions

## Outcome

The crash screen uses the medium panel width of 500 CSS pixels, capped by
the viewport and its safe insets. Copy and primary Reload share one row when
the error details are open. With only Reload visible, the button centers.
Each single-line action is 48 CSS pixels high, including while pressed.

Chromium checks confirmed the mounted panel at 720×360, 1280×720 and
420×360. Copy, keyboard focus, forced colours, hold and reload were checked.
Reload preserved the existing save. Short panels expose the error stack in
its own scrollable area so both actions remain visible.
