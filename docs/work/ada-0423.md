## Scope

Raise the centre-line flow in Whirlpool from 70 to 105 world units per second.

## Criteria

- Retain existing placement, geometry, falloff, and object eligibility.
- Confirm the new peak and the existing edge and end taper through the normal
  flight current calculation.

## Outcome

The stronger Whirlpool flow landed in `eec5ef6d2`. The flight current test
checks 105 units per second at the centre line and the edge and end taper.
`ddfafcf20` checks the matching visual flow. The implementation is included in
public build `ec2ce101c`.
