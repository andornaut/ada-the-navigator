## Scope

Order the Paused card's actions for flight and Earth, add its Quests entry, and set where Map and Ship lead.

## Criteria

- The flight Paused card is a two-column grid: Quests and Ship, then Map when permitted and Settings, then Back to title and primary Resume.
- Resume is the same size as the other actions, at the bottom right beside Back to title.
- Earth's Map opens the galaxy map and flight's Map the local map; Ship's primary Back returns to Paused.

## Decisions

- Shared actions keep one order in both contexts, and Map shows only when the model permits it.
