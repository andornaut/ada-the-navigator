## Scope

Convert game UI icons to source-driven SVGs across Settings, onboarding and
control help, Shop, Jobs & Projects, Ship and detail cards, and resource UI.
Keep pixel art in world sprites and effects. Preserve painted UI art, skins and
sprite animations.

## Criteria

- Art owns simple, smooth SVG exports under the existing sprite keys. Keep
  existing dimensions and state names. Review every icon at its native size
  and preserve disabled art and multicolour ink where they distinguish states.
- Tech inventories current callers and pairs each cutover with matching assets.
  Keep existing icon meaning, layout, control states and accessibility. Use
  established weapon, ammo and map masks where they match the approved art.
- Keep runtime raster assets until caller, archive, precache and offline coverage
  are verified. Remove obsolete assets only after their last runtime use.
- Verify actual rendered controls and first use, including disabled states and
  offline loading. Measure changes in emitted files and encoded package size.
  The checked source follows normal delivery.
