## Scope

Adopt game-kit's published button skin, reveal the first screen after boot art decodes, pin the
published layout tree API, and compose every card, pager, footer and panel through typed trees and
native layout ports.

## Criteria

- Action registries, availability, modal lifecycle and return context stay outside tree data.
- Every card uses the published renderer or native layout ports.
- Boot art readiness is bounded by the loader timeout with a fallback reveal.

## Decisions

- The public UI facade stays unchanged.
- Request `approved-configUI`.
