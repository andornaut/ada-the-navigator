## Scope

On a resize that moves the raster scale, re-rasterise only the textures the current scene draws,
not every SVG loaded from every galaxy; rasterise the others lazily on their first draw.

## Criteria

- Container memory per resize stays flat both without and after a forced collection, and the
  browser smoke's ten-resize probe asserts it once the fix lands.
- No visible texture is stale or blurred after a resize.

## Decisions

- Each resize that moved the raster scale rasterised every loaded SVG again, from every galaxy,
  so each one left a full set of replaced images and textures in the renderer. That set was the
  growth retained after a collection, about 60 MB a resize, and the garbage before it.
- `SvgRasters.resize` now only marks loaded SVGs stale. Each frame after drawing, `rasterDrawn`
  rasterises again the stale SVGs that a visible game object shows or that a reveal or salvage
  group stamped (`SvgRasters.mark`); the rest wait for their first draw. An SVG whose scale is
  current again by the time it is drawn is not rasterised at all. While a storybook page covers
  the flight scene nothing is drawn, so nothing is rasterised until the page closes.
- The smoke's resize probe runs last, in a browser of its own, so the checks before it leave it
  no memory to inherit.

## Outcome

Resizes alternate between 1280x720 and 720x360 in flight, in the browser check's container
(2 GiB limit). Container memory at each resize:

| Build                         | Resizes 1 to 10                                                | Live WebGL textures | Result            |
| ----------------------------- | -------------------------------------------------------------- | ------------------- | ----------------- |
| Before, no collection         | 1213, 1417, 1626, 1828 MiB                                     | 562, then 611 flat  | Crashes at step 5 |
| Fix, no collection            | 1158, 1180, 1161, 1184, 1159, 1201, 1194, 1224, 1206, 1236 MiB | 609 flat            | No crash          |
| Before, after each collection | 1279, 1388, 1343, 1390, 1349, 1442, 1370, 1437, 1353, 1488 MiB | 537 flat            | Rising            |
| Fix, after each collection    | 989, 978, 967, 986, 967, 989, 955, 982, 963, 982 MiB           | 541 flat            | Flat              |

Unit tests cover drawn-only re-rasterising, hidden objects, stamped frames and a scale that
returns before a draw. The browser smoke's ten resizes, without and then with a collection after
each, assert live textures, canvases created and container memory flat, and its screenshots after
the resizes match fresh views at both sizes.
