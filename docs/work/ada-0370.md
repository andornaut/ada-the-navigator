## Scope

Show ordinary in-flight speech for 3 seconds plus 50 ms per character.
Set the shared speech and game notice background to 0.55 alpha.

## Criteria

- Keep existing game and network notice timings, scan receipt and emergency
  warning timing, and conversation order and interruption behavior.
- Keep the text, name tab and portrait opaque. Preserve the station panel and
  save status background. Review the speech and notice over a bright field.

## Decisions

- Use 0.55 alpha in place of the earlier proposed 0.60.
