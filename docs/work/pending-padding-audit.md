## Scope

Measure the drawn-pixel padding of every pill and button not yet audited, against the rule that padding and margins are equal as drawn, counting icon side bearings. Deliver a mock-up sheet of mismatches with proposed fixes for user review before any production change.

## Criteria

- Each pill and button is measured on rendered pixels at 1280x720 and 720x360 with phone insets.
- Each mismatch lists the element, the measured sides, the rule value and the proposed fix.
- No source or asset changes before the user approves the fixes.
