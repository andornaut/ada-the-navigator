## Scope

Define Ada's guarded click and hold policy and bind every registered action, through owned input
roots and modal scopes, to game-kit's published hold dispatcher, with construction audits proving
each discrete binding.

## Criteria

- Native clicks are guarded by the captured UI scope.
- Pointer release resolves from the current physical hit.
- The architecture check requires execution dominance for each discrete binding.

## Decisions

- The 500 ms hold is passed explicitly.
- Station, Interaction and layout refusal integration continues as a separate task.
