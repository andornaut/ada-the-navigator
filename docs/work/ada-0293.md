## Scope

Pin game-kit 0.58.2, which keeps a complete build selected when an activation fails and checks
installed entries by presence on switch, plus delivery-kit 5.0.2 and the coordination-kit 1.0.2
devDependency.

## Criteria

- Each pin is the published tarball with lockfile integrity matching its release.
- The full gate passes on the exact revision, and a fresh install with the Cloudflare headers
  reaches Start in emulated Android Chrome.

## Decisions

- The single install event and its time limit on slow links are fixed separately in game-kit 0.59.0.

## Outcome

`package.json` and `package-lock.json` pin game-kit 0.58.2, delivery-kit 5.0.2 and
coordination-kit 1.0.2.
