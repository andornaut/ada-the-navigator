## Scope

Stop emitting and delete the 814 files under `public/art/` that Ada never loads: 736 turret-top frames for weapon designs no hardpoints layout carries, 73 portrait JSONs, `holodisk.json`, `holodisk-beacon.json`, `ship-retro-jets-yellow.json`, `app-icon/icon.svg` and `app-icon/contact-sheet.png`. `enemies/destruction-flash.svg` stays. The two archie portrait JSONs that `art/tools/character-check.ts` reads move out of `public/art/`.

## Criteria

- No file under `public/art/` is unreferenced by a manifest, a runtime path or a JSON the runtime loads.
- Producers no longer emit the removed files, and every producer reruns byte-identical.
- Before and after file counts and compressed bytes are reported.

## Decisions

## Outcome

The producers stop emitting the 814 files and they are removed from `public/art/`;
`ship-retro-jets-yellow.json` moves to `art/sources/`, where its test reads it, and
`enemies/destruction-flash.svg` stays. Art's audit finds every remaining file referenced by a
manifest, a runtime path or a loaded JSON.
