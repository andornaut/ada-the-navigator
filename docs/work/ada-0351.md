## Scope

Stop repeatedly allocating and discarding identical keyline textures
while drawing animated world objects. Keep the existing keyline paint,
render scale, motion and sampling.

## Criteria

- Reuse identical source regions and release unused textures after a
  source, scale or ink change. Bound idle textures and clear scene-owned
  textures on teardown.
- Use the existing browser settle and resize checks. Verify that a paused
  flight settles, draws at the current scale after each resize, and
  retains stable texture and canvas counts across repeated resizes.
- Record the checked source, rendered evidence and normal delivery.
