## Scope

Keep Ada's 64 headings and continuous steering and aim. First use the current hull and
procedural jet geometry in place of the generated thrust fallback frames, then retire
the 64 thrust SVGs and any obsolete aliases. After that stage is verified, use the shared
material geometry for Classic in flight, local and route maps, title, shop and applicable
effects before retiring the 64 standalone Classic idle SVGs.

Tech owns the consumer and integration. Art owns production assets, their documentation
and visual verification.

## Criteria

- Both stages preserve exact scale, pivot, headings, paint, collision outlines, nose
  positions and existing visual effects. Verify Classic, purchased paints and normal and
  reverse jets in actual play, plus affected nonflight views.
- The thrust path preserves real loading failures and existing retry behavior. Cold
  install, offline boot and cached updates resolve a coherent package without fetching
  retired frames or mixing asset versions.
- Verify each stage against the actual emitted build and measure raw artifact and
  package transfer bytes. Record actual transfer conditions with the measurements.
- Pair the consumer, producer and Art documentation before each stage ships through
  normal delivery.
