## Scope

A delivery job's description (`questDeliveryDetail`) and a supply run's description
(`questSupplyDetail`) name their places by the same sentence names as the title and objective,
such as "the workshop" or "the station", whether or not the place is mapped. Only the From and
To endpoint lines show "Explore to locate" for an unmapped place.

## Criteria

- An unmapped delivery destination reads by its sentence name in the description, and its To
  endpoint still shows "Explore to locate".
- An unmapped supply run source and destination read by their sentence names in the description,
  and both endpoints still show "Explore to locate".
- `gameplay/quests.md` documents both strings and the rule, landing with the source change.

## Decisions

- The descriptions use the existing sentence-name resolver, so they always match the title and
  objective; the endpoint lines alone withhold unmapped places.
