## Criteria

- Keep the Start screen Restart control and its existing confirmation.
- Keep the selective reset for jobs, projects and quests in Cheats.

selective reset. Exact Chromium checks covered Start, Pause, return focus
and cancellation of Restart with the save intact. Deployed in `b8b447bd`.
