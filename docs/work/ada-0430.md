## Scope

Use Next for linear dialogue and Previous to retrace the pages a player
visited. Show authored choices on topic lists and forks. Remove Ask more.

## Criteria

- Return to selectable topics when an optional thread ends. Indicate a read
  topic once its thread reaches the end, with an accessible label.
- Mark quest-advancing options with the existing quest icon. Keep named
  exits, Skip behavior, and all material outcomes.
- Preserve visit history through page turns and station screens. End the
  standalone visit on close or undock. Use the safe landscape game viewport.

## Outcome

Replayable topics and visited-page history landed in `a7f95bd2c` and
`47558425f`. `9ca22090a` covers the same history through a visible Continue
click and reload. The exact Chromium storybook smoke on public build
`ec2ce101c` followed the unread-topic path and checked Previous navigation.
