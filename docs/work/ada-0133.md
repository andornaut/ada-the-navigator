## Scope

State what Art owns, how producers in `art/tools/` regenerate assets, and move shared raster, colour and build helpers onto the published ArtKit package.

## Criteria

- `art/README.md` names the Art-owned paths, the producer contract and the project's Node requirement, with no container execution rule.
- Producers import grayscale, Lanczos, Gaussian, inverse Oklab and raster helpers from ArtKit's canonical build entry points instead of local copies.
- The unused local rounded rectangle raster helper is removed.
- ArtKit's optional font peer is recorded in the lock file.

## Decisions

- Shared helpers come from the published kit so every game's producers draw identical pixels from one source.
