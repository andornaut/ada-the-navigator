# Ada the Navigator gameplay

The game name is Ada the Navigator. A gameplay brief covering genre, mechanics,
story and input has not yet been provided. Current scope is infrastructure only.

## Ownership

Gameplay owns this directory, game rules, gameplay data and values, and player
strings. Rules, values and player copy require an approved brief before authoring.
Tech owns implementation, tooling and integration. Art owns art direction and
assets in `art/` and `public/art/`.

## Handoff interface

Gameplay hands approved rules, data definitions and player text to Tech with the
source branch, base commit and exact commit to integrate. Tech and Gameplay agree
on the implementation interface when an approved brief supplies its requirements.

Gameplay supplies Art with approved presentation requirements and references to
the corresponding rules and text. Art supplies asset references and usage details
for Tech to integrate. No gameplay or production asset requirements are defined
by this infrastructure document.
