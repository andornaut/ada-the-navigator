# Portraits

Approved portraits reused from the Archie repository (`andornaut/archies-dog-walks`) at exact commit `8124ae5a9281e67b51191d8a9a609fc7f76480af`.

Copyright (c) 2026 andornaut. Source portraits are licensed under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
The [source licence](portraits-LICENSE.txt) is included unchanged. PNGs are
unchanged; JSON metadata uses local image filenames and normalized formatting.

Ada is the brown/dark-skinned girl depicted in the source art. The dog portrait retains the source appearance; no breed or character name is assigned here. Penny is the golden dog portrait (`face-dog-penny`).

The `casey`, `trista` and `mr-b` assets are reusable community portraits from Archie. These filenames and preserved source frame keys identify asset provenance only; they assign no Archie identity, story, age or NPC role in Ada. Tech selects the frame for each character. Each portrait includes a neutral expression at frame 1.

## Geometry and tags

Every frame is 32 × 32 pixels, untrimmed, with a 1000 ms duration. The Ada, casey, trista and mr-b sheets are 64 × 32 pixels; the dog and Penny sheets are 96 × 32 pixels.

| Portrait | happy   | neutral | upset       |
| -------- | ------- | ------- | ----------- |
| Ada      | Frame 0 | Frame 1 | Not present |
| casey    | Frame 0 | Frame 1 | Not present |
| Dog      | Frame 0 | Frame 1 | Frame 2     |
| mr-b     | Frame 0 | Frame 1 | Not present |
| Penny    | Frame 0 | Frame 1 | Frame 2     |
| trista   | Frame 0 | Frame 1 | Not present |

PNG files are byte-for-byte copies. The only JSON data change is `meta.image` to the corresponding destination PNG filename. Source frame keys, geometry, durations and tags are preserved.

`ada-compact.png` and `penny-compact.png` are adaptations under the same
licence: exact 22 × 22 crops of each frame, generated by
`art/tools/portraits.ts` with the source tags and durations. The Astra and
General Gadget sheets are authored for Ada. Both are described in
[Conversation portraits](conversation.md).

## Storybook sprite source

`art/sources/face-walker-ada.png` is a byte-identical copy of the Archie source
`public/art/sprites/face-walker-ada.png` at the pinned commit above (SHA-256
`46633962fb8d3d4757954009b614a940d0e918dccb90e350b4b7e60d2f9deaa3`, the same
bytes as `public/art/portraits/ada.png`), under the same licence.
`art/tools/ada-sprites.ts` reads its neutral frame for the head of Ada's
storybook sprites ([storybook](storybook.md#adas-sprites)) and adapts it there;
the portrait files above stay unchanged.
